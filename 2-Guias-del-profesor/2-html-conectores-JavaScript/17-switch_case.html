17 switch case

switch permite evaluar una variable frente a varios casos de forma ordenada y clara.

Ejemplo de referencia

const opcion = 2; switch (opcion) { case 1: console.log("Uno"); break; default: console.log("Otro"); }

La salida principal del ejemplo se muestra en la consola del navegador con F12 > Console. Este bloque sirve como referencia visual del concepto y el script real sigue ejecutándose en consola.
