# Fundamentos Frontend

Repositorio de apoyo para el aprendizaje de HTML, CSS, JavaScript y fundamentos de React.

## Estructura del curso

### 1. 1-Curso-JavaScript
* **A-Pruebas-js-moderno**: ejercicios prácticos y actividades para reforzar conceptos de JavaScript moderno.
* **B-JavaScript-Moderno**: introducción a ES6+, sintaxis moderna y conceptos clave para prepararse para React.
* **C-React-fundamentos**: bases para entender patrones, componentes y lógica reactiva desde JavaScript.

### 2. 2-Guias-del-profesor
* **1-html-semantico**: ejemplos de estructura HTML semántica, formularios, media y maquetación.
* **2-html-conectores-JavaScript**: archivos HTML que conectan teoría con ejemplos de JavaScript.
* **2-JavaScript-**: referencia de scripts del profesor con ejemplos de operadores, condicionales, arreglos, objetos, funciones y más.
* **4-archivos-JSON**: archivos de datos de apoyo para consumir información.
* **PDFs**: material adicional del curso.

### 3. 3-Arquitecturas-css
* **css-box-model**: práctica del modelo de caja.
* **css-flexbox**: diseño con flexbox.
* **css-grid**: diseño con grid.
* **INDEX.html**: punto de entrada visual para la sección de CSS.

## Extensiones recomendadas para VS Code

Para trabajar sin problemas con HTML, CSS y JavaScript en este curso, recomiendo estas extensiones:

### Esenciales
* **Live Server**: abre la página en un navegador y recarga al guardar.
* **Prettier - Code formatter**: formatea el código automáticamente para mantenerlo limpio y legible.
* **ESLint**: detecta errores, malas prácticas y ayuda a mantener código más profesional.
* **Auto Close Tag**: cierra etiquetas HTML y JSX automáticamente.
* **Auto Rename Tag**: renombra etiquetas de cierre cuando cambias la apertura.
* **HTML CSS Support**: mejora el autocompletado para clases y estilos.
* **IntelliSense for CSS class names in HTML**: ayuda a completar clases CSS dentro de HTML.
* **JavaScript (ES6) code snippets**: agrega fragmentos útiles para escribir código más rápido.

### Opcionales pero muy útiles
* **GitHub Copilot**: ayuda a explicar conceptos, generar ejemplos y acelerar la práctica.
* **Material Icon Theme**: mejora la organización visual de los archivos en el explorador.
* **Bracket Pair Colorizer**: facilita la lectura de bloques anidados.
* **Code Runner**: ejecuta fragmentos rápidos de JavaScript y pruebas sencillas.
* **Path Intellisense**: ayuda a completar rutas en HTML, CSS y JS.
* **TODO Highlight**: marca tareas pendientes o anotaciones importantes.

## Resumen
Este repositorio está organizado para separar claramente:
- fundamentos de JavaScript,
- guías del profesor,
- ejemplos HTML y CSS,
- y material de apoyo para practicar con una estructura más clara y profesional.

El objetivo es que el aprendizaje sea más didáctico, visual y fácil de seguir durante el curso.
